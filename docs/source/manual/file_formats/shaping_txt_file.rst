Shaping (.txt)
--------------

The `Shaping.txt` file is generated by the Floorplan tool in AAEE.  
It is used to describe the detailed location and dimension information of modules after the floorplanning stage for an FPGA fabric.  
The file includes precise details for each instance and module, such as:

- Instance name
- Module name
- Location coordinates (x, y)
- Height
- Width

The instance and module information is inferred from the internal data structure `tileref`.
