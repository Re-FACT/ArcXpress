Netlist Development
===================

This tutorial describes the **netlist development flow** for an eFPGA
architecture. It is a direct follow-up to the :ref:`tutorial_arch_flow`
section.

In the Architecture Development flow, the eFPGA architecture has been fully
defined and validated, including the specification of logic blocks, routing
resources, and connectivity. However, the architecture description itself is
not yet synthesizable or suitable for physical analysis.

This tutorial is based on the AlkaidL example eFPGA architecture, which was completed in the previous section. Using this same architecture, we demonstrate a complete netlist development flow that transforms the architecture description into RTL- and gate-level netlists, and evaluates the design using coarse analysis, floorplanning, and Quality-of-Result (QoR) metrics.

By completing this flow, users will obtain:

- RTL-level netlists generated from the architecture description
- Optimized gate-level netlists suitable for analysis
- Coarse area and resource utilization reports
- Coarse floorplanning results for the eFPGA fabric
- Timing, area, and power QoR reports

Netlist Development Flow
~~~~~~~~~~~~~~~~~~~~~~~~

This section walks through the netlist development flow step by step using the
same example architecture. Each command represents one stage of the flow and
produces outputs that are consumed by subsequent stages.

.. note::

   The netlist development commands must be executed in the following order:

   1. ``generate_netlist``
   2. ``optimize_netlist``
   3. ``coarse_analyze_netlist``
   4. ``coarse_floorplan``
   5. ``extract_netlist_qor``

   Each command depends on the outputs generated by the previous step.
   Skipping any step will prevent subsequent commands from running
   successfully.

.. _generate_netlist_example:

generate_netlist
^^^^^^^^^^^^^^^^

**Purpose:**
Generate RTL-level netlists and the base bitstream from the completed eFPGA
architecture description.

Basic Usage
"""""""""""

.. code-block:: bash

   arcxpress> generate_netlist

You can still use the command :ref:`show_status` and :ref:`show_dashboard` command to check the status.
The usage is as follows:

.. code-block:: text

   arcxpress> show_status
   arcxpress> show_dashboard

Successful Execution Flow
"""""""""""""""""""""""""

If the run is successful, you will see the following log output.

.. code-block:: text

   Initializing netlist directory...
   Generating RTL netlists
   Generating base bitstream

Generated Files
"""""""""""""""

- RTL netlist files
- Base bitstream file
- Log files
- Run records

The generated file path is under `alkaid_ex_netlist/iter0/netlist`. You can see the generated files by searching the path.

**Debugging Tips**

Use ``--verbosity 1`` for detailed logs:

.. code-block:: bash

   arcxpress> generate_netlist

For full options, see :ref:`arcxpress_netlist_dev_commands_generate_netlist`.

.. _optimize_netlist_example:

optimize_netlist
^^^^^^^^^^^^^^^^

**Purpose:**
Optimize the RTL netlist and generate a gate-level netlist for the example
architecture.

Basic Usage
"""""""""""

.. code-block:: bash

   arcxpress> optimize_netlist

You can still use the command :ref:`show_status` and :ref:`show_dashboard` command to check the status.
The usage is as follows:

.. code-block:: text

   arcxpress> show_status
   arcxpress> show_dashboard

Successful Execution Flow
"""""""""""""""""""""""""
If the run is successful, you will see the following log output.

.. code-block:: text

   Initializing SDC files for netlist synthesis
   Done
   Read Synthesis Strategy File
   Read fabric hierarchy file to find sub-blocks under tiles
   Done
   Apply CCFF makeup...
   Done
   Run netlist synthesis...
   Done
   Importing external PDK netlists...
   Done

Generated Files
"""""""""""""

- Gate-level netlist files
- Synthesis reports (timing, area, power)
- Technology mapping results
- Log files
- Run records

The generated file path is under `alkaid_ex_netlist/iter0/netlist`. You can see the generated files by searching the path.

**Debugging Tips**

.. code-block:: bash

   arcxpress> optimize_netlist  --verbosity 1

For full options, see :ref:`arcxpress_netlist_dev_commands_optimize_netlist`.

extract_netlist_qor

.. code-block:: text
